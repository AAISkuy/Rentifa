
# Rentifa - Vehicle Rental Platform

> "Reliable Rides, Easy Rentals"

Platform web aplikasi penyewaan kendaraan terintegrasi yang dirancang untuk memudahkan pengguna dalam mencari, memesan, dan mengelola penyewaan kendaraan baik mobil maupun motor secara online dengan cepat, transparan, dan aman.

## 🚀 Tech Stack

- **Frontend:** React, TypeScript, Vite, React Router, Custom CSS/Tailwind
- **Backend:** Node.js, Express.js, TypeScript (`tsx`), `mysql2`, `bcryptjs`, `dotenv`
- **Database:** MySQL (`rentifa_db`)

## 📂 Project Directory Structure

- `/backend` - REST API Server, Controllers, Models, Routes, dan Middleware
- `/frontend` - SPA Client, Components, Pages, API Services, dan Layouts
- `/docs` - Dokumentasi Teknis, PRD, ERD, dan Todo Roadmap
